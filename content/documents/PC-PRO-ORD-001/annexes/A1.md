titre: Liste de vérification avant transmission d'un ordre
nature: Liste de contrôle
renseigne_par: Desk ; automatisée dans le Guichet pour les points marqués ●

frequence: Pour chaque ordre, avant transmission

Un ordre n'est transmis que si toutes les cases applicables sont cochées. Les points marqués ● sont contrôlés par le Guichet ; le desk vérifie les autres.

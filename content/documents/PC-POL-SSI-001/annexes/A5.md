La colonne « En place » est cochée lors de chaque vérification ; une mesure absente devient une action du plan de contrôle.

| Outil | Mesures minimales | Qui | Vérification | En place |
| --- | --- | --- | --- | --- |
| Ordinateurs portables | Chiffrement du disque ; mises à jour automatiques ; antivirus actif ; verrouillage à 5 minutes ; pas de droits d'administration pour l'utilisateur ; effacement à distance possible | Prestataire | Semestrielle | ☐ |
| Téléphones professionnels | Code de verrouillage ; mises à jour ; effacement à distance ; applications professionnelles seulement pour les données de clients | Référent informatique | Semestrielle | ☐ |
| Messagerie et bureautique en ligne | Authentification à plusieurs facteurs pour tous ; paramètres de sécurité par défaut activés ; compte d'urgence sous scellé ; transfert automatique externe bloqué ; alertes de connexion ; SPF, DKIM et DMARC publiés | Prestataire, Directeur Général | Trimestrielle | ☐ |
| Guichet | Second facteur obligatoire au desk ; séparation proposition et approbation ; journal d'audit chaîné vérifié ; relecture avant fusion sur la branche de production ; secrets dans les variables protégées ; plafonds de dépense des API | Responsable du Guichet | Trimestrielle | ☐ |
| Base de données du Guichet | Accès console nominatif avec second facteur ; sauvegardes automatiques et copie externe ; clef de service jamais exposée côté client | Responsable du Guichet | Trimestrielle | ☐ |
| Site internet et nom de domaine | Second facteur chez l'hébergeur et le registraire ; verrou de transfert du domaine ; renouvellement automatique ; certificat HTTPS | Directeur Général | Annuelle | ☐ |
| Banque en ligne | Double signature des paiements ; jetons individuels ; plafonds ; alertes | Directeur Général | Semestrielle | ☐ |
| Coffre-fort de mots de passe | Second facteur ; partage par dossier selon le besoin ; accès de secours défini | Référent informatique | Semestrielle | ☐ |
| Sauvegardes | Trois copies, deux supports, une hors ligne ou chez un autre fournisseur ; restauration testée | Prestataire | Trimestrielle | ☐ |
| Réseau du bureau | Mot de passe Wi-Fi robuste ; réseau invités séparé ; équipement à jour ; double accès internet | Prestataire | Annuelle | ☐ |
